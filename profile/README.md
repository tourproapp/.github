# TourPro

TourPro is tour management software for live music. Schedules, travel, flights, hotels, guest lists, advances, and day sheets in one place for band, crew, and management.

- Web, iOS, Android, and desktop apps
- Live flight tracking with automatic delay and cancellation alerts
- Shared schedules with per-role permissions

**[tourpro.app](https://tourpro.app)**

This org hosts small open-source utilities extracted from the TourPro codebase. The apps themselves are closed source.

## Projects

| Repo | What it is |
